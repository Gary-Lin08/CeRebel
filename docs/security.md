# 安全与隐私

CeRebel 处理的是人体动作视频和从中重建的身体模型，在美国属于生物特征相关数据（伊利诺伊州 BIPA、德州和华盛顿州的类似法律、美国司法部的数据安全规定）。下面的规则不是建议，改代码时必须守住。

## 必须遵守的规则

**密钥**

- 所有密钥只放在服务器的 `.env.product` 和各服务商后台。不要写进代码、提交、issue、聊天记录或截图。`.gitignore` 已忽略 `.env`、`.env.*`、`*.pem`、`secrets/`。
- 操作员密码只从环境变量 `MOTION_AGENT_PROMPT_PASSWORD` 读取，比较时用 `hmac.compare_digest`，只接受请求头，不接受查询参数（会进访问日志）。
- 登录令牌只在桥接设备或浏览器里，不写进眼镜固件。

**谁能看到什么**

- 匿名访客只能看到 `CEREBEL_DEMO_SESSION_ID` 指定的那一个会话。不要再加"没有归属的会话默认公开"之类的逻辑（以前出过这个问题）。
- 每个读接口在没传会话 ID 时，只能落到"当前账号最新的会话"或演示会话，**不能**落到全局最新的会话。
- `/media/` 只认服务端签发、6 小时有效的签名链接，或者有权限的登录请求；被删除的会话即使链接没过期也拒绝。
- 操作员功能（提示词编辑、切换模型后端、运营统计）只在 `CEREBEL_OPERATOR_PORT`（只绑 127.0.0.1）上提供。

**对外的接口**

- 出错时只返回给用户看的消息和 `error_id`，堆栈只写服务器日志。
- 跨域只放行 `CEREBEL_ALLOWED_ORIGINS`，从不返回 `*`。
- 内部服务（8090、8091、8093、61016、61017）只绑本机。
- 用户能控制的路径（静态文件、媒体文件、会话 ID）先 `resolve()` 再检查是否还在允许的目录里，防止 `../` 穿越；会话 ID 只允许 `[A-Za-z0-9_-]`。
- 有请求体的接口先限制 `Content-Length`。

**用户的视频和数据**

- 上传前必须取得单独的视频处理同意（`/api/account/video-consent`），没同意时一个字节都不写盘。
- 默认不把视频帧发给语言模型（`CEREBEL_LLM_ATTACH_VIDEO=0`），取画面的工具也不提供给模型，模型只看到问题和工具算出的数字。新加的工具如果会返回画面，必须登记到 `RGB_TOOL_NAMES`。
- 原视频和帧在处理完 30 天后删除，24 个月不活跃的账号整体删除（`retention.py` 每天运行）。GEM-X 输出的头部形状系数清零（`hpe_privacy.py`）。
- 删除账号要删干净：账号、令牌、所有会话目录、GPU 侧的输出、作品库行、本地订阅记录、埋点里的行。新增任何按用户存储的数据，都要接进 `product_api.remove_account`、`retention.py` 和 `privacy_backfill.py`。
- 匿名访客的 IP 只以每日轮换密钥的 HMAC 形式落盘。
- 换服务商或机房，要改同意文本里的处理方列表并提升版本号。

**结论的诚实**

- 给用户看的数字只能来自确定性代码，不能让语言模型编。
- 估算出来的力和负荷必须标明"估算"，不做医疗诊断，不承诺治疗或防伤效果。
- 识别不出是哪项运动时，诚实地说没识别到（`no_swing`），不要硬套高尔夫。

## 已知风险

尚未修复的风险清单由负责人单独维护，**不写进这个公开仓库**。接手开发前向负责人要最新的清单。发现新的风险时，按下面的方式私下报告，不要开公开 issue，也不要写进提交信息或文档。

## 报告安全问题

发邮件到 garylin@cerebel.tech，不要开公开 issue。写清楚复现步骤和影响范围。

## 代码审查清单

提 PR 前自查，审查者逐项确认：

- [ ] 没有密钥、令牌、真实用户数据、内部服务器地址进入代码或测试数据
- [ ] 新接口检查了登录和归属（`user_may_view_session` / `media_allowed`），匿名只能看演示会话
- [ ] 用户输入的路径、ID、长度都有校验
- [ ] 出错不返回堆栈，异常写日志并返回 `error_id`
- [ ] 新增的按用户存储的数据，删除账号和数据保留任务都能删掉
- [ ] 给用户看的数字来自工具，估算值有标注
- [ ] 改了接口就同步改了 `sdk/openapi.yaml`、两个 SDK 和模拟服务器
