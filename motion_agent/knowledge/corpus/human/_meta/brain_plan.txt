================================================================================
1. PURPOSE & SCOPE
================================================================================

Deliver RAG-ready knowledge for **sport-agnostic human motion** from monocular or multi-view body capture.
Analysis emphasizes posture stack (head–rib–pelvis), balance, limb–torso coordination, and prep → action →
recover timing visible on the skeleton.

In scope v1:
- Standing, stepping, squatting, lunging, reaching, jump/throw prep patterns
- 14 finding cards with cues and drills
- Cross-link measurement policy to sibling opensim_motion_tools.txt

Out of scope v1:
- Medical diagnosis, pathology naming, rehab protocols
- Sport-specific technique optima (defer to sport packs when matched)
- Implement / ball tracking

Build agent writes Findings/Coaching bodies from this map.

2. PRODUCT CONSTRAINTS

================================================================================
3. PHASE MODEL (ONE MOVEMENT REP)
================================================================================

Phase IDs (exact — for Phases/001_phase_model.txt):

| id              | label_en        | role |
|-----------------|-----------------|------|
| setup           | Setup / Ready   | Organized stack, weight balanced |
| prep            | Preparation     | Wind-up, eccentric, counter-movement |
| load            | Load / Transfer | Weight acceptance, COM over base |
| action          | Action          | Peak effort, max segment speeds |
| follow_through  | Follow-through  | Deceleration, finish path |
| recover         | Recovery        | Return toward neutral stack |
| reset           | Reset           | Ready for next rep |

Event definitions (body-only):

- setup_event (E_SETUP): pelvis speed minimal or clip start.
- prep_end_event (E_PREP_END): max eccentric flexion or COM backward velocity minimum before action.
- action_peak_event (E_ACTION_PEAK): max wrist/ankle speed or extension velocity peak.
- recover_end_event (E_RECOVER_END): stack variance returns toward setup band.

Handedness / side: findings tag side=left|right|bilateral where applicable.

================================================================================
5. EVIDENCE-BANDED NORMS (NOT MEDICAL PRESCRIPTION)
================================================================================

ADULT (authority mostly B+ / B):

- Stack: moderate deviation at setup triggers posture_stack_break only when load/action worsens OR sustained gross deviation.
- Forward head: sagittal proxy beyond conservative band — educational, not cervical diagnosis.
- Knee valgus: flag only frontal/oblique confidence; neuromuscular training themes B+.
- Balance sway: top quartile vs self-baseline on single-leg task when ≥2 trials in clip.

YOUTH (U14):

- Widen shoulder_height and stack checkpoints (cp_*_youth rows in Quality/002).
- Do not apply adult FHP shaming language.
