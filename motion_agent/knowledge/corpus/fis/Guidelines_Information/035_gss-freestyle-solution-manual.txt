Starting the software 
Right-click "Freestylesolution.exe" and run it as administrator. 
 
 
 
Upon running Freestylesolution.exe a window opens , where you can choose your  database ‘.sdf’  file. 
Please select  Main A and  click the  three dots to select the database  of your competition. Then click 
"Connect to Database and Start". This is how you start the Main Instance.

--- page 5 ---

Working with Main and Client Instances 
 
Do all the pre-event setup in the Main Instance (which you start by choosing “Main A”). 
 
After assigning the start order, please close the Main Instance. 
 
Then you may restart it and leave it running in the background but do not open any windows there. 
 
Everything that is done during the competition (e.g. live scoring, online judging, pdf results, score validation, 
timing) should be opened in Client Instances.  
 
You can start as many Client Instances as you like.  
It is recommended to open a separate Client Instance for every task. 
It is possible to utilize more than one computer for these operations. If the judges' tablets are set up (as in 
Europa Cup), you can add additional computers to the same network (via a switch) and run the Client 
Instances on them (see chapter Judges’ Tablets). 
  
 
 
 
- To start the Client Instance, run “Freestylesolution.exe” and choose “Client” instead of “Main A” 
 
- A window pops up where you should click “Connect and Start” 
 
- If this window does not appear click “start as slave”
