# Baseball Pitching — Concept Taxonomy (v1, UI-aligned)

## Primary concepts

concept_id: baseball_pitching
label_en: Baseball pitching (overhand)
definition: Cyclical throwing motion from rubber toward catcher; CeRebel analyzes body keypoints without ball track.
synonyms_en: pitching, pitch delivery, windup delivery
synonyms_zh: 棒球投球, 投手动作
authority: B

concept_id: pitch_phase_model_v1
label_en: Six-phase UI pitch model
definition: set → lift → stride → landing → release → follow; matches sport_analysis._baseball_window.
authority: ProductLogic

## UI phase concepts (exact ids)

concept_id: phase_set
label_en: Set
label_zh: 预备
ontology: baseball:phase_set
body_focus: balance on rubber, minimal COM drift

concept_id: phase_lift
label_en: Leg lift
label_zh: 抬腿
ontology: baseball:phase_lift
body_focus: drive knee lift, gather

concept_id: phase_stride
label_en: Stride
label_zh: 跨步
ontology: baseball:phase_stride
body_focus: lead leg toward plate, separation window opens

concept_id: phase_landing
label_en: Landing
label_zh: 前脚着地
ontology: baseball:phase_landing
body_focus: lead foot contact, bracing, separation at landing

concept_id: phase_release
label_en: Release
label_zh: 出手
ontology: baseball:phase_release
body_focus: throwing-hand speed peak (release proxy)

concept_id: phase_follow
label_en: Follow-through
label_zh: 随挥
ontology: baseball:phase_follow
body_focus: deceleration, arm across body
