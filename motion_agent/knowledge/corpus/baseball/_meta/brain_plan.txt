3. PHASE MODEL (UI + DETECTOR ALIGNMENT)
================================================================================

Phase IDs (exact — match sport_analysis._baseball_window):

| id       | label_en      | label_zh     | role |
|----------|---------------|--------------|------|
| set      | Set           | 预备/setup   | Quiet on rubber; minimal COM drift |
| lift     | Leg lift      | 抬腿         | Lead knee rises; balance on drive leg |
| stride   | Stride        | 跨步         | COM moves toward plate; foot in air |
| landing  | Landing       | 前脚着地     | Lead foot contact → stable base |
| release  | Release       | 出手         | Throwing-hand speed peak (proxy for release) |
| follow   | Follow-through| 随挥         | Deceleration after release peak |

Event definitions (body-only, OpenSim-friendly):

- release_event: argmax ||v(trail_wrist)|| in analysis window (NOT ball release).
- landing_event: last strong deceleration of lead_ankle speed before release_event
  (see _landing_time); fallback: ~18% of window span before release.
- set_end: start + 12% window span (or first meaningful COM motion — future).
- lift_end: max(set_end, landing - 28% span).
- stride: lift_end → landing_event.
- landing phase: landing_event → landing_event + 8% span (min 20 ms).
- release phase: end(landing) → release + 6% span.

Handedness: trail = throwing side; lead = glove side (RHP: trail right, lead left).

Detector pitch_likeness features (document in Biomechanics/001, not duplicated here):
- wrist speed burst (peak/median), lead ankle stride_ratio, throwing vs glove wrist arm_ratio.
- Enable live only when DETECTOR_ENABLED + labeled suite passes; golf block always on.

Phases/001_phase_model.txt (build): expand events, fallback behavior, scrub UX copy.

5. CLINICAL / COACHING NORMS (EVIDENCE-BANDED)
================================================================================

Use as RAG reference bands, NOT individual medical advice. Build agent adds URLs in
SOURCE_MANIFEST + research_notes. Wording: "typical in published cohorts".

ADULT (college/pro male overhand; authority mostly A / B+):

- Stride length (foot contact): ~75–90% of body height; coaching consensus often
  cites ~85% height (B+). Product checkpoint: flag "short" < ~70%, "long" > ~95%
  (adjust for capture scale — normalize by stature estimate from model height metadata
  or shoulder–ankle segment if available).
- Hip–shoulder separation at foot contact: often ~40–60° in EMG/kinematic studies (A);
  product "low separation" heuristic currently < 25° at landing (code) — KB should
  explain why conservative for noisy monocular OpenSim.
- Max external rotation (MER) at shoulder: frequently reported ~165–180° in pro pitchers (A);
  youth: lower absolute values normal; do NOT use 170° as youth target.
- Lead knee flex at foot strike: often ~35–55° (A/B+); excessive collapse = increase
  > ~8–15° from landing to release (matches code front-knee rule).
- Trunk tilt (forward): variable by style; flag extreme upright or hyper-flexion only
  with multi-study B+ backing in Biomechanics doc.
- Pelvis rotation velocity peak: typically precedes trunk then arm (kinematic sequence, A).

YOUTH CAVEATS (Little League / middle school; authority B+ / clinical consensus):

- Shorter stride relative to height; slower tempo; lower MER; emphasis on control &
  volume limits (USA Baseball / MLB Pitch Smart — A+ for volume, B+ for mechanics).
- Avoid cueing "throw as hard as pros"; findings severity down-weight for < 14 yrs
  unless pain/injury language (then safety redirect, not drill prescription).
- Open growth plates: no weighted-ball drill prescriptions in product KB.

Evidence levels for pack (see section 6): every numeric checkpoint lists one level.
