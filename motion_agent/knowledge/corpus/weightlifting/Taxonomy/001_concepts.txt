# Weightlifting (Barbell Squat / Hinge / Press) — Concept Taxonomy (v0.1)
# Aligns: _meta/brain_plan.txt, Schema/001_ontology.txt, SPORT_PACK_KB_SPEC

## Primary concepts

concept_id: barbell_strength_form
label_en: Barbell strength form (squat, hinge, press)
definition: Body-first analysis of squat, deadlift-style hinge, and press patterns using reconstructed joints; no bar mass or bar tracking required.
synonyms_en: weight training form, barbell technique, SBD form
synonyms_zh: 杠铃力量训练, 深蹲硬拉推举技术
parent: weightlifting
authority: ProductLogic

concept_id: safety_first_coaching
label_en: Safety-first coaching gate
definition: Pain, injury, and environment checks run before form findings; product refuses drill prescription when safety gates fail.
synonyms_en: pain stop, red flag screening
related_phases: all
authority: A

concept_id: lift_family_squat
label_en: Squat lift family
definition: Bilateral knee-dominant pattern with bar on upper back; phase chain sq_setup → sq_rerack.
synonyms_en: back squat, barbell squat
synonyms_zh: 杠铃深蹲, 背蹲
authority: B+

concept_id: lift_family_hinge
label_en: Hinge / deadlift family
definition: Hip-dominant pull from floor with neutral spine intent; phase chain dl_setup → dl_reset.
synonyms_en: deadlift, conventional pull, RDL (variant)
synonyms_zh: 硬拉, 髋铰链
authority: B+

concept_id: lift_family_press
label_en: Press family
definition: Vertical or horizontal barbell press; OHP default phase chain pr_setup → pr_rerack; bench shares IDs with floor-start note.
synonyms_en: overhead press, bench press, strict press
synonyms_zh: 推举, 卧推, 站姿推举
authority: B+

concept_id: spinal_neutrality_proxy
label_en: Spinal neutrality (posture proxy)
definition: Visible lumbar extension/bending trends under load; not diagnostic of tissue injury; used for squat and hinge findings.
synonyms_en: neutral spine cue, braced trunk
related_series: series_lumbar_extension, series_lumbar_bending, series_trunk_lean_proxy
authority: B+

concept_id: bracing
label_en: Trunk bracing
definition: Pre-movement stiffening of trunk before descent or pull; sq_brace, dl_brace phases.
synonyms_en: 360° brace, Valsalva (coach context only — not medical)
related_phases: sq_brace, dl_brace, pr_setup
authority: B+

## Squat phase concepts (align wlift:phase_sq_*)

concept_id: phase_sq_setup
label_en: Squat setup
start_event: clip_start_or_stillness
end_event: E_SQ_BRACE_START
body_focus: stance width, bar position proxy, foot tripod

concept_id: phase_sq_brace
label_en: Squat brace
start_event: E_SQ_BRACE_START
end_event: E_SQ_DESCENT_START
body_focus: ribcage over pelvis, minimal knee flex

concept_id: phase_sq_descent
label_en: Squat descent
start_event: E_SQ_DESCENT_START
end_event: E_SQ_BOTTOM
body_focus: controlled knee/hip flex, heel contact

concept_id: phase_sq_bottom
label_en: Squat bottom
start_event: E_SQ_BOTTOM
end_event: E_SQ_ASCENT_START
body_focus: turnaround, depth proxy via knee flex

concept_id: phase_sq_ascent
label_en: Squat ascent
start_event: E_SQ_ASCENT_START
end_event: E_SQ_LOCKOUT
body_focus: hip and chest rise together, knee tracking

concept_id: phase_sq_lockout
label_en: Squat lockout
start_event: E_SQ_LOCKOUT
end_event: E_SQ_RERACK_START
body_focus: full knee/hip extension, stable trunk

concept_id: phase_sq_rerack
label_en: Squat rerack
start_event: E_SQ_RERACK_START
end_event: clip_end_or_stillness
body_focus: controlled walk-back to rack if visible

## Hinge phase concepts (align wlift:phase_dl_*)

concept_id: phase_dl_setup
label_en: Deadlift setup
start_event: clip_start_or_stillness
end_event: E_DL_BRACE_START
body_focus: shin-over-bar proxy, hip height, grip hang

concept_id: phase_dl_brace
label_en: Deadlift brace
start_event: E_DL_BRACE_START
end_event: E_DL_BREAK
body_focus: lats long, neutral lumbar intent

concept_id: phase_dl_break
label_en: Break from floor
start_event: E_DL_BREAK
end_event: E_DL_KNEE_PASS
body_focus: shoulders and hips rise together; no hip shoot

concept_id: phase_dl_knee_pass
label_en: Knee pass
start_event: E_DL_KNEE_PASS
end_event: E_DL_LOCKOUT
body_focus: leg drive, bar/hands pass knee height proxy

concept_id: phase_dl_lockout
label_en: Deadlift lockout
start_event: E_DL_LOCKOUT
end_event: E_DL_LOWER_START
body_focus: hip extension, avoid hyperextension

concept_id: phase_dl_lower
label_en: Deadlift lowering
start_event: E_DL_LOWER_START
end_event: E_DL_RESET
body_focus: controlled eccentric if present in clip

concept_id: phase_dl_reset
label_en: Deadlift reset
start_event: E_DL_RESET
end_event: next_rep_or_clip_end
body_focus: return to setup between reps

## Press phase concepts (align wlift:phase_pr_*)

concept_id: phase_pr_setup
label_en: Press setup
start_event: clip_start
end_event: E_PR_UNRACK
body_focus: grip width, wrist stack, feet planted

concept_id: phase_pr_unrack
label_en: Unrack
start_event: E_PR_UNRACK
end_event: E_PR_ECCENTRIC_START
body_focus: clear rack, stable starting position

concept_id: phase_pr_eccentric
label_en: Press eccentric
start_event: E_PR_ECCENTRIC_START
end_event: E_PR_DRIVE_START
body_focus: bar path to chin/chest band; elbows under wrists proxy

concept_id: phase_pr_drive
label_en: Press drive
start_event: E_PR_DRIVE_START
end_event: E_PR_LOCKOUT
body_focus: leg drive (OHP), rib-pelvis stack, vertical hand path proxy

concept_id: phase_pr_lockout
label_en: Press lockout
start_event: E_PR_LOCKOUT
end_event: E_PR_RERACK_START
body_focus: elbow extension, bar over mid-foot proxy

concept_id: phase_pr_rerack
label_en: Press rerack
start_event: E_PR_RERACK_START
end_event: clip_end
body_focus: safe return to hooks

## Event concepts

concept_id: event_sq_bottom
label_en: Squat bottom event
definition: Frame of maximum mean knee flexion in rep window.
detector: E_SQ_BOTTOM
synonyms_en: turnaround, hole

concept_id: event_sq_lockout
label_en: Squat lockout event
definition: Pelvis vertical height peak after bottom.
detector: E_SQ_LOCKOUT

concept_id: event_dl_break_floor
label_en: Deadlift break floor
definition: Onset of upward hand/wrist vertical velocity after setup stillness.
detector: E_DL_BREAK

concept_id: event_dl_lockout
label_en: Deadlift lockout event
definition: Hip extension complete; pelvis height peak or min hip flexion post-pull.
detector: E_DL_LOCKOUT

concept_id: event_pr_drive_peak
label_en: Press drive peak
definition: Maximum upward hand vertical velocity during concentric.
detector: E_PR_DRIVE_PEAK
